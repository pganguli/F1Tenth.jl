API

The layers mirror the Python package: the gym environment, the simulator and its cars, then the dynamics, collision and LiDAR models.

Environment

F1Tenth.F110Env — Type
F110Env(; seed=12345, map="vegas", map_ext=".png", params=VehicleParams(), num_agents=2,
          timestep=0.01, ego_idx=1, integrator=Integrator.RK4, lidar_dist=0.0)

The F1TENTH gym environment, with the keyword arguments of Python's gym.make('f110_gym:f110-v0', **kwargs):

  • seed: seed of the LiDAR noise
  • map: "berlin", "skirk", "levine", "vegas", a track from f1tenth_racetracks such as "Austin" or "Spa" (downloaded on first use; see F1Tenth.RACETRACKS), or the path of a map yaml file without its extension
  • map_ext: extension of the map image, such as ".png" (built-in maps default to their own)
  • params: a VehicleParams or a dict with all of its keys
  • num_agents: number of cars
  • timestep: physics time step in seconds
  • ego_idx: index of the ego car (1-based)
  • integrator: Integrator.RK4 or Integrator.Euler
  • lidar_dist: distance from the rear axle to the LiDAR

Drive it with reset!, step! and render!.

F1Tenth.step! — Function
step!(sim::Simulator, control_inputs) -> Observation

Advance every car one step. control_inputs is num_agents × 2: desired steering angle in column 1, desired speed in column 2.

source
step!(env::F110Env, action) -> (obs, reward, done, info)

Advance one time step. action is num_agents × 2: desired steering angle in column 1, desired speed in column 2. reward is the time step; done is true once the ego car crashes or every car has done two laps; info.checkpoint_done[i] is true once car i has.

The returned Observation and info are overwritten by the next call.

F1Tenth.Observation — Type
Observation

What step! and reset! return: the entries of Python's observation dict (ego_idx, scans, poses_x, poses_y, poses_theta, linear_vels_x, linear_vels_y, ang_vels_z, collisions, lap_times, lap_counts). Read them as obs.poses_x, obs[:poses_x] or obs["poses_x"].

The arrays are reused: each step overwrites them. copy(obs) keeps a snapshot.

Rendering

F1Tenth.EnvRenderer — Type
EnvRenderer

The render window, passed to render callbacks. Like Python's renderer it works in renderer units (50 × meters). Callbacks may set the camera (left, right, bottom, top) and score_label, read cars[i][] (corner points of car i), poses (num_agents × 3, meters) and ego_idx, and draw on axis with GLMakie (where Python callbacks add to batch).

F1Tenth.RaceCar — Type
RaceCar(params, seed; is_ego=false, time_step=0.01, num_beams=1080, fov=4.7,
        integrator=Integrator.Euler, lidar_dist=0.0)

One vehicle: dynamics, a two-step steering delay, the speed/steering controller and a LiDAR. state is (x, y, steer_angle, vel, yaw_angle, yaw_rate, slip_angle). Scan noise is drawn from scan_rng; set it to nothing for noise-free scans (as rng=None in Python).

Cars made by a Simulator share its scan simulator and beam tables, like the class attributes of Python's RaceCar.

F1Tenth.VehicleParams — Type
VehicleParams(; mu=1.0489, C_Sf=4.718, C_Sr=5.4562, lf=0.15875, lr=0.17145, h=0.074,
                m=3.74, I=0.04712, s_min=-0.4189, s_max=0.4189, sv_min=-3.2, sv_max=3.2,
                v_switch=7.319, a_max=9.51, v_min=-5.0, v_max=20.0, width=0.31, length=0.58)
VehicleParams(d::AbstractDict)

Vehicle parameters. Same keys and defaults as the Python env's params dict:

  • mu: surface friction coefficient
  • C_Sf, C_Sr: front/rear cornering stiffness coefficients
  • lf, lr: distance from the center of gravity to the front/rear axle
  • h: height of the center of gravity
  • m: total mass of the vehicle
  • I: moment of inertia of the vehicle about the z axis
  • s_min, s_max: steering angle limits
  • sv_min, sv_max: steering velocity limits
  • v_switch: velocity above which acceleration can no longer spin the wheels
  • a_max: maximum longitudinal acceleration
  • v_min, v_max: longitudinal velocity limits
  • width, length: car body size in meters

A dict (String or Symbol keys) must hold every key, as in Python; extra keys are ignored.

Performance settings

F1Tenth.TRACER — Constant
F1Tenth.TRACER[] = :auto | :simd | :scalar

LiDAR tracer to use. Both give identical scans; :auto (the default) picks the faster one for this CPU on first use.

source
F1Tenth.THREAD_AGENTS — Constant
F1Tenth.THREAD_AGENTS[] = true | false

With more than one Julia thread, step each car on its own thread (default true). Set to false when running many simulators in parallel yourself.
